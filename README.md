# 🎵 Spotify Clone

A Spotify-inspired music player UI built using **HTML and CSS** as part of my frontend web development learning journey.

## 📌 About the Project

This project is a frontend recreation of the Spotify Web Player interface.

The main goal of this project was to practice building a real-world website layout and improve my understanding of **HTML structure, CSS styling, Flexbox, responsive design, and UI interactions**.

## 🚀 Features

- 🎵 Spotify-inspired dark theme
- 🏠 Home and Search navigation
- 📚 Your Library section
- 🎶 Recently Played section
- 📊 Featured Charts section
- 🎧 Music player interface
- 🔍 Search bar UI
- ❤️ Like button UI
- 🔊 Volume control UI
- 🖱️ Hover effects and transitions
- 📱 Basic responsive behavior

## 🛠️ Technologies Used

- HTML5
- CSS3
- Font Awesome
- Google Fonts
